# Пивоскан 1.1 — цены из магазинов

**[Скачать APK 1.1](https://github.com/xloded01-afk/pivoskan/releases/download/v1.1/Pivoskan-1.1.apk)** ·
[Все файлы релиза](https://github.com/xloded01-afk/pivoskan/releases/tag/v1.1) ·
[Отчёт о проверке](VERIFICATION.md)

Android-приложение на Kotlin. Загружает предложения официальных каталогов непосредственно
с телефона. Компьютер и собственный сервер не нужны; для обновления требуется интернет.

## Установка и обновление

1. Перенесите `dist/Pivoskan-1.1.apk` на телефон с Android 7.0 или новее.
2. Откройте APK и разрешите установку этому файловому менеджеру, если Android запросит.
3. Если установлена переданная ранее подписанная версия 1.0, установите обновление поверх неё.
   Ключ подписи и пакет приложения сохранены. Город и тема сохраняются.
4. Выберите город. Балашиха и ещё 11 городов Подмосковья находятся в списке рядом с Москвой.

В шапке есть кнопка обновления. Кнопка с адресом Магнита позволяет выбрать другую точку.
В «Источниках» видны результаты загрузки каждой сети и ссылки на официальные каталоги.
Меню содержит смену города, тему и описание данных.

## Какие цены загружаются

| Сеть | Поддержка | Область действия |
|---|---|---|
| Магнит | Прямая загрузка | Конкретный выбранный магазин; адрес указан |
| Fix Price | Прямая загрузка | Каталог выбранного города; по адресам цены могут отличаться |
| Дикси | Автозагрузка недоступна | Официальный запрос товаров возвращает 403; доступна ссылка на каталог |
| Пятёрочка | Автозагрузка недоступна | Официальный сайт ограничивает автоматический доступ; доступна ссылка на каталог |

**Демонстрационных цен в новой версии нет.** При сбое доступны только ранее сохранённые
реальные данные с датой; для нового города без кеша показывается причина отсутствия данных.

Цены хранятся в целых копейках. Цена по карте Fix Price отображается отдельно от обычной.
Если источник возвращает диапазон цен вариантов, приложение показывает диапазон.
Срок акции показывается только если он известен. Данные сайтов могут меняться;
наличие, условия карты и итоговую цену следует проверить у продавца.

Сравнение охватывает загруженные предложения, **не все магазины города**.
Магнит предоставляет список до 100 найденных адресов для выбора одной точки.
Товары объединяются только при одинаковом нормализованном названии: приблизительные
совпадения разных марок, крепости или объёма не используются.

## Города

Москва; Балашиха, Химки, Мытищи, Королёв, Люберцы, Одинцово, Красногорск, Реутов,
Подольск, Долгопрудный, Пушкино, Щёлково; Санкт-Петербург, Краснодар, Екатеринбург,
Новосибирск, Казань и Нижний Новгород. Название и регион проверяются по ответу источника.
Если сеть не вернула выбранный город, цены Москвы или другого города не подставляются.

## Сборка

Требуются JDK 17+, Android SDK Platform 35 и Build-Tools, принятые лицензии SDK.
Откройте папку проекта в Android Studio и дождитесь синхронизации либо используйте PowerShell:

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_HOME = 'C:\Users\YOUR_NAME\AppData\Local\Android\Sdk'
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Check
```

Результат — `dist/Pivoskan-debug.apk`. Скрипт использует отдельную папку результатов в `%TEMP%`,
чтобы JDK 17/Windows корректно выполняла тесты при кириллице в пути проекта.
После первой загрузки зависимостей можно добавить `-Offline` к сборке.
Это не отключает интернет в самом приложении.

Для подписанного обновления в исходной рабочей папке сохранены `pivoskan-release.jks`
и `keystore.properties`. В архив исходников секреты не входят.
Сохраните эти два файла отдельно для следующих обновлений и не публикуйте их.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Release -Check
```

Результат — `dist/Pivoskan-1.1.apk`. В распакованных исходниках можно собрать debug без ключа,
а для собственного подписанного релиза — создать ключ через keytool и заполнить
`keystore.properties` по образцу `keystore.properties.example`.
Новый ключ не позволяет установить обновление поверх APK, подписанного старым ключом.

Обычные Gradle-команды:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintRelease :app:assembleDebug
# Дополнительная проверка настоящих запросов (нужен интернет):
.\gradlew.bat :app:liveCatalogSmoke
```

При кириллице в пути добавьте `-PpivoskanBuildDir=C:/Temp/pivoskan-build`.
Live smoke проверяет именно production-код HTTPS-клиента и источников в Балашихе.
Обычные модульные тесты работают без сети на сохранённых минимальных ответах сайтов.

## Основные файлы

- `data/CityCatalog.kt` — города и сети, без базы выдуманных товаров/цен.
- `data/remote/MagnitSource.kt`, `FixPriceSource.kt` — проверка города/магазина и ответы каталогов.
- `data/remote/HttpsTransport.kt` — HTTPS, таймауты, ограничения размера ответа.
- `data/Models.kt`, `OfferQuery.kt` — предложения в копейках, поиск и сортировка.
- `data/CatalogLoader.kt` — частичные ошибки и кеш нужного города/магазина.
- `data/CatalogRepository.kt`, `SnapshotCodec.kt`, `CatalogViewModel.kt` — кеш и фоновое обновление.
- `MainActivity.kt`, `CityPickerActivity.kt`, `BeerDetailsActivity.kt` — экраны.
- `ui/BeerAdapter.kt`, `CompareAdapter.kt` — карточки и сравнение.
- `res/layout/`, `res/values/strings*.xml`, `res/values-night/` — разметки, тексты, темы.
- `app/src/test/` — тесты и минимальные настоящие ответы без токенов и пользовательских данных.

Источник данных — публичные методы официальных сайтов; договорного стабильного API нет.
Если сайт изменится или ограничит доступ, приложение покажет сбой источника, а не выдуманную цену.
Иллюстративная карта внутри приложения остаётся схемой; для настоящего адреса доступны внешние карты.

Результаты проверки и ограничения — в `VERIFICATION.md`; контрольные суммы — в `dist/SHA256SUMS.txt`.
