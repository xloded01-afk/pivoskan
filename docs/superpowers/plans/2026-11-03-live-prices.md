# Реальные цены — план реализации

> **For agentic workers:** Use superpowers:executing-plans and independently scoped parallel workers.

**Goal:** Обновить APK до 1.1: реальные цены Магнита и Fix Price, города Подмосковья, честные статусы недоступных сетей.
**Architecture:** Models/CityCatalog + чистые парсеры и query; HTTPS-клиент/источники; репозиторий с кешем; lifecycle ViewModel и существующие XML-экраны.
**Spec:** docs/superpowers/specs/2026-11-03-live-prices-design.md

- [x] 1. Общие модели в копейках, каталог городов/сетей, тесты query и денег. Удалить генерацию mock-цен из production.
- [x] 2. Парсеры и источники Магнита/Fix Price, HTTPS-клиент с таймаутами/проверкой хоста и региона, тесты настоящих ответов и отрицательных случаев.
- [x] 3. Репозиторий, кеш города/магазина и ViewModel: фоновые запросы, защита от устаревших ответов, частичный сбой не удаляет успешные реальные данные.
- [x] 4. Главный экран: обновление, статус источников, выбор магазина Магнита, обычная/клубная цена, область действия и дата. CityPicker и детали используют новые модели.
- [x] 5. Live smoke-запрос к подтверждённым источникам, все тесты, сборки/Lint, независимое ревью и исправления. Пересобрать 1.1 прежним ключом, проверить подпись и permission INTERNET, обновить инструкцию/архив/контрольные суммы.

Проверяемые риски: неверная география, поздний ответ после смены города, округление копеек, неподтверждённая клубная цена, пропущенные страницы, отсутствие сети/403/повреждённый кеш. Старый APK 1.0 не заменяется.
