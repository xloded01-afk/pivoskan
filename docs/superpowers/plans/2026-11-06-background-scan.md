# Фоновый обход города

Новый запрос пользователя отменяет прежнее ограничение «только при видимом приложении».
Реализовать один начатый обход после сворачивания и блокировки экрана через dataSync foreground service.
Не добавлять периодическое расписание без выбора пользователя. Уведомление: город, адресный прогресс,
кнопка остановки, открытие приложения. Завершение/отмена/таймаут останавливают сервис.
Смена города заменяет обход; возвращение и поворот экрана не создают дубликат.
Service START_NOT_STICKY: не запускать новый обход после уничтожения процесса автоматически.
Работа без сервера, источники остаются прежними. Браузерные сети не объявлять поддержанными.

1. Добавить тестируемую политику доступа к сети (видимость либо действующий foreground service),
   проверку окончания при COMPLETE/PARTIAL/UNAVAILABLE/NEEDS_LOGIN/NEEDS_ACTION/CANCELLED; RED→GREEN.
2. Добавить сервис, manifest permissions/type dataSync, уведомление/остановку/timeout и ограниченный wake lock.
   Запуск сервиса только из видимого приложения; startForeground до начала сетевой работы.
3. Перенаправить Runtime в сервис, исключить отмену при Home/ScreenOff в активном сервисе,
   сохранить ручную отмену и защиту поколений. Обработать ошибку запуска сервиса.
4. Запросить POST_NOTIFICATIONS на Android 13+, повысить versionCode/versionName, собрать APK,
   выполнить unit tests и lint. Проверка Home/lock/cancel/return/complete на телефоне остаётся обязательной.
