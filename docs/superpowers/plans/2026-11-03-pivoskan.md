# Пивоскан — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать офлайн-приложение на Kotlin, которое показывает самое дешёвое пиво в выбранном городе по сетям Магнит, Дикси, Пятёрочка и Fix Price, и отдать подписанный APK.

**Architecture:** Один модуль `app`, классические Views + XML + ViewBinding, Material 3. Данные — детерминированный генератор из мок-каталога (`PriceEngine`), без БД и сети. Экраны: онбординг с городом → список предложений → детали с офлайн-картой. Настройки — `SharedPreferences`.

**Tech Stack:** Kotlin 2.0.21, AGP 8.7.3, Gradle 8.9, JDK 17, compileSdk/targetSdk 35, minSdk 24, Material Components 1.12.0, RecyclerView, ViewBinding, core-splashscreen.

**Spec:** `docs/superpowers/specs/2026-11-03-pivoskan-design.md`

## Global Constraints

- Пакет `ru.pivoskan.app`, имя приложения «Пивоскан», одно activity-приложение без интернета.
- В `AndroidManifest.xml` **нет** разрешения `INTERNET` и `ACCESS_NETWORK_STATE`.
- minSdk 24, targetSdk 35, compileSdk 35; только портретная ориентация не фиксируется.
- Никакого Compose, RxJava, Hilt, Room, Retrofit. Зависимости — только из списка выше.
- Все строки интерфейса — в `res/values/strings.xml`, на русском, без хардкода в layout/kt (кроме логов).
- Палитра и типографика — строго из раздела 6 спеки (значения ниже в задаче 2).
- Цены — целые рубли, формат `1 299 ₽` с неразрывным пробелом; объём `0,5 л`, `0,33 л`, `0,45 л`.
- Тема: светлая/тёмная, по умолчанию системная; ручной выбор сохраняется.
- Все тап-зоны ≥ 48 dp, отступы экрана 20 dp, радиусы карточек 20 dp.
- Рабочая сборка: `JAVA_HOME=<temp>/jdk17`, `ANDROID_HOME=<temp>/sdk`, Gradle 8.9 локально.

## Review Focus

1. Поиск с пустой строкой, пробелами и «ё» — «Жигули»/«жигули»/«ЖИГУЛИ»/«жЕгули» должны находить одну и ту же марку, пустой запрос — весь список.
2. Быстрое переключение чипов и сортировки — без дублей, миганий и падений (`DiffUtil`, стабильные id).
3. Поворот экрана и возврат с экрана деталей — фильтры, поиск и сортировка на месте, текущий город не теряется.
4. Один магазин с этой маркой — блок «В других магазинах» скрыт, а не пустая рамка.
5. Телефон без приложения карт — «Открыть в картах» не падает, показывает снекбар или открывает веб-карты.

```kotlin
@Test fun `каждый город даёт минимум 30 предложений`() {
    MockCatalog.cities.forEach { assertEquals(true, PriceEngine.offers(it.id).size >= 30) }
}
@Test fun `цены различаются по городам и сетям`() {
    val msk = PriceEngine.offers("msk").associateBy { it.beer.id + it.store.id }
    val spb = PriceEngine.offers("spb").associateBy { it.beer.id + it.store.id }
    assertTrue(msk.any { (k, v) -> spb[k] != null && spb[k]!!.price != v.price })
    assertTrue(PriceEngine.offers("msk").groupBy { it.beer.id }.any { it.value.map { o -> o.price }.distinct().size > 1 })
}
@Test fun `скидка консистентна`() {
    PriceEngine.offers("msk").forEach {
        if (it.discountPercent > 0) { assertTrue(it.oldPrice!! > it.price); assertTrue(it.discountPercent in 25..45) }
        else assertNull(it.oldPrice)
    }
}
@Test fun `поиск нормализует регистр и ё`() {
    assertEquals(PriceEngine.offers("msk").count { it.beer.id.startsWith("zhiguli") },
        PriceEngine.query("msk", emptySet(), "ЖИГУЛИ", SortMode.CHEAPEST).size)
    assertEquals(PriceEngine.offers("msk").size, PriceEngine.query("msk", emptySet(), "   ", SortMode.CHEAPEST).size)
}
@Test fun `фильтр по сети и сортировки`() {
    val only = PriceEngine.query("msk", setOf("magnit"), "", SortMode.CHEAPEST)
    assertTrue(only.all { it.offer.store.id == "magnit" })
    val cheap = only.map { it.offer.price }; assertEquals(cheap.sorted(), cheap)
    val disc = PriceEngine.query("msk", emptySet(), "", SortMode.DISCOUNT).map { it.offer.discountPercent }
    assertEquals(disc.sortedDescending(), disc)
}
@Test fun `минимальная цена помечена ровно у одной строки на марку`() {
    val rows = PriceEngine.query("msk", emptySet(), "", SortMode.CHEAPEST)
    rows.groupBy { it.offer.beer.id }.forEach { (_, g) -> assertEquals(1, g.count { it.isBest }) }
}
@Test fun `генерация стабильна между вызовами`() {
    assertEquals(PriceEngine.offers("kzn"), PriceEngine.offers("kzn"))
}
```
