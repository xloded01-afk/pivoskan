# Проверка на Android: обход города

Статус: ожидает устройства. JVM-тесты не заменяют этот список.

- [ ] Обновление поверх 1.3, ранее выбранный Магнит на Кудаковского: обход других адресов.
- [ ] Балашиха: два реальных магазина Магнита, сохранение обоих после перезапуска.
- [ ] Home: новые запросы прекращаются, при возвращении новый runId.
- [ ] Выключение экрана/блокировка: запросов нет до разблокировки и видимого приложения.
- [ ] Поворот: тот же runId, без одновременных дублей.
- [ ] Карточка товара/назад: тот же runId и все адреса доступны.
- [ ] Вход в официальный каталог/назад: тот же runId; закрытие входа не равно успешной авторизации.
- [ ] Смена города во время запроса: старые ответы не меняют новый кеш.
- [ ] Отмена: самопроизвольного повторного запуска нет.
- [ ] Убийство процесса: завершённые магазины сохранены, при запуске новый обход.
- [ ] Потеря сети: старые цены с датой; ошибка одной сети не блокирует другие.
- [ ] Дикси: пользовательский вход, два адреса, полная пагинация либо честная недоступность.
- [ ] Пятёрочка: пользовательский вход, два адреса, полная пагинация либо честная недоступность.
- [ ] Обычные/карточные/городские/старые цены различимы; разные упаковки не объединены.
- [ ] Изображение отсутствует/ошибка: цены остаются; переработанная строка не показывает чужую картинку.
- [ ] Длинные адреса, увеличенный шрифт, TalkBack и раскрытие нескольких товаров.

Для каждого пункта записать устройство, Android/WebView, версию APK, дату и результат.
Секреты аккаунта, cookies и персональные страницы в отчёт не включать.
