# Фоновый обход — проверка Android 1.4

Это новая модель поведения: прежние требования остановки при Home/блокировке отменены.
Проверки ниже пока не выполнены на реальном устройстве.

- [ ] Запуск выбора города: появляется одно уведомление с городом и прогрессом.
- [ ] Home и блокировка: счётчик продолжает расти, результаты сохраняются.
- [ ] Возврат и поворот экрана: тот же обход, счётчик не сбрасывается.
- [ ] Отмена в уведомлении: уведомление исчезает, новые запросы не начинаются.
- [ ] Отмена в приложении: тот же результат; возвращение само не возобновляет отменённый обход.
- [ ] Смена города: результаты старого города не попадают в новый.
- [ ] Полное/частичное завершение: уведомление исчезает, адресные результаты сохранены.
- [ ] Отказ в разрешении уведомлений Android 13+: нет падения; остановка из приложения работает.
- [ ] Android 15 timeout: сервис завершается без ANR; кеш завершённых магазинов сохранён.
- [ ] Уничтожение процесса и принудительная остановка: новый обход сам не запускается.
- [ ] Проверить ограничения батареи realme: не обещать непрерывную работу при запрете фона системой.

dataSync foreground service, START_NOT_STICKY, bounded partial wake lock; без загрузочного
receiver, периодического расписания и собственного сервера. Ручная проверка телефона нужна:
JVM-тесты и lint не доказывают реальную работу при блокировке и ограничениях производителя.
